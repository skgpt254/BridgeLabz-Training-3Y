Responsive Design Principles

Fluid Layouts

Flexible sizes adapt to available width.

width: 100%;
max-width: 1200px;

Flexible Media

Media should shrink inside its container.

img {
 max-width: 100%;
 height: auto;
}

Breakpoints

Breakpoints change layout when needed.

@media (max-width: 600px)
